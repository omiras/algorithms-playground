Ejercicio 7 · Decidir el acceso y mostrar un mensaje

Nivel básico

Antes de empezar

Puedes evaluar un booleano con if…else para elegir el mensaje que se escribe en la consola.

const reservaConfirmada = true;
if (reservaConfirmada) {
  console.log("La mesa está reservada");
} else {
  console.log("La mesa está libre");
}

Tu turno

En la recepción de un evento internacional, cada ficha contiene el nombre, la edad y el país de una persona. La aplicación necesita decidir el acceso y explicarlo en la consola.

Completa isAdultInCountryWithObject(person) con los límites del ejercicio: 18 años para «España» y 21 para «EEUU». Después, usa un if…else para cada ficha dentro de showAdultMessages(). Muestra exactamente «Carlos no es adulto en España» y «John es adulto en EEUU», según los booleanos que devuelve la función.

Edita el cuerpo de las dos funciones y abre la consola con F12 → Consola para ver los mensajes. Guarda el archivo y recarga la página.
