Ejercicio 2 · Aplicar el límite de edad según el país

Nivel básico

Antes de empezar

Elige primero el límite en función de un dato y compáralo después con el valor recibido.

const sala = "grande";
const asistentes = 12;
let aforo = 10;
if (sala == "grande") {
  aforo = 30;
}
console.log(asistentes < aforo); // true

Tu turno

Un portal tiene reglas de acceso distintas para sus dos sedes. Recibe la edad de la persona y el país de la sede que ha seleccionado.

Completa isAdultInCountry(age, country). Para «España» el límite del ejercicio es 18 años y para «EEUU» es 21. Devuelve un booleano. Solo recibirás esos dos países.

Edita el cuerpo de la función del bloque <script> dentro de <body>. Guarda el archivo y recarga la página.

Resultado esperado

isAdultInCountry(17, "España"): false
isAdultInCountry(18, "España"): true
isAdultInCountry(20, "EEUU"): false
isAdultInCountry(21, "EEUU"): true
isAdultInCountry(21, "España"): true
