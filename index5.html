Ejercicio 5 · Organizar a los participantes por parejas

Nivel básico

Antes de empezar

length indica cuántos elementos hay. El operador % devuelve el resto de la división.

const entradas = ["A", "B", "C", "D", "E"];
console.log(entradas.length % 2); // 1

Tu turno

En un taller, cada participante necesita una pareja para la siguiente actividad. La organización tiene una lista con los nombres y quiere saber si alguien se quedará sin pareja.

Completa canWeMakePairs(names). Devuelve true si todos pueden agruparse de dos en dos y false si sobra una persona. La lista contiene al menos un nombre.

Edita el cuerpo de la función del bloque <script> dentro de <body>. Guarda el archivo y recarga la página.

Resultado esperado

canWeMakePairs(["Alice","Bob","Charlie","David"]): true
canWeMakePairs(["Alice","Bob","Charlie"]): false
canWeMakePairs(["Alice","Bob"]): true
canWeMakePairs(["Alice"]): false
