Ejercicio 8 · Sumar únicamente los depósitos

Nivel intermedio

Antes de empezar

Inicializa un acumulador antes del bucle y actualízalo solo si el elemento cumple la condición.

let puntos = 0;
for (const valor of [5, 12, 3]) {
  if (valor < 10) {
    puntos += valor;
  }
}
console.log(puntos); // 8

Tu turno

El historial de una cuenta muestra ingresos y retiradas en la misma lista. La persona que consulta el historial quiere saber cuánto dinero ha ingresado en total durante el periodo.

Completa sumDeposits(deposits). Suma los importes positivos y devuelve el total como número. Las retiradas son negativas. Si no hay depósitos, devuelve 0.

Edita el cuerpo de la función del primer bloque <script> dentro de <body>. Guarda el archivo y recarga la página.
