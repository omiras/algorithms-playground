Ejercicio 8 · Sumar únicamente los depósitos

Nivel intermedio

Antes de empezar

Inicializa un acumulador antes del bucle y actualízalo solo si el elemento cumple la condición.

let puntos = 0;
for (const valor of [5, 12, 3]) {
  if (valor < 10) {
    puntos += valor;
  }
}
console.log(puntos); // 8
