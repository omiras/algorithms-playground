# Razonamiento algorítmico en JavaScript

Abre el HTML de un ejercicio directamente en el navegador. Lee el ejemplo de «Antes de empezar» y el enunciado de «Tu turno». Edita el cuerpo indicado, guarda el archivo y recarga la página. La sección «Comprueba tu solución» se actualiza sola y muestra la entrada, el valor esperado y el obtenido. En el ejercicio 7 también puedes abrir la consola con **F12 → Consola**.

| [2](index2.html) | Básico | Aplicar el límite de edad según el país |
| [3](index3.html) | Básico | Saludar en el idioma elegido |

La rama `node` conserva los ejercicios originales. La rama `solution-html` contiene las soluciones.
