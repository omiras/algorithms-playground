Ejercicio 10 · Preparar un diccionario de palabras de cinco letras

Nivel intermedio

Antes de empezar

La propiedad length cuenta los caracteres de las palabras del ejercicio. El índice indicado por la longitud del array señala la siguiente posición libre.

const cortas = [];
for (const palabra of ["sol", "nube", "mar"]) {
  if (palabra.length == 3) {
    cortas[cortas.length] = palabra;
  }
}
console.log(cortas); // ["sol", "mar"]

Tu turno

Un juego de adivinar palabras necesita preparar su lista de posibles respuestas. El diccionario contiene palabras de distintas longitudes, pero todas las respuestas del juego tienen cinco letras.

Completa getWords5Letters(words). Devuelve un array nuevo con las palabras de exactamente cinco letras. Conserva el orden y las repeticiones de la lista original. Si ninguna coincide, devuelve un array vacío.

Edita el cuerpo de la función del bloque <script> dentro de <body>. Guarda el archivo y recarga la página.

Resultado esperado

getWords5Letters(["mesa","silla","cuchara","tenedor","cama"]): ["silla"]
getWords5Letters(["perro","gato","loro","pez","ciervo"]): ["perro"]
getWords5Letters(["sol","luz","mar","cielo","sol"]): ["cielo"]
getWords5Letters(["sol","luz","mar","sol"]): []
getWords5Letters(["cielo","silla","cielo"]): ["cielo","silla","cielo"]
