Ejercicio 11 · Buscar un patrón dentro de una secuencia

Nivel intermedio

Antes de empezar

El método includes de una cadena busca un fragmento dentro de ella. Puedes devolver true en cuanto encuentres la primera coincidencia.

console.log("pedido-urgente-12".includes("urgente")); // true
console.log("pedido-normal-15".includes("urgente")); // false

Tu turno

En una simulación de laboratorio, cada muestra tiene varias secuencias ficticias guardadas como cadenas. Para marcar una muestra, el programa busca el patrón de texto «ATCGGCTA» en cualquiera de sus secuencias.

Completa checkDNAForAlzheimer(sequences). Devuelve true si al menos una cadena contiene «ATCGGCTA» en cualquier posición, y false si ninguna lo contiene. Una lista vacía devuelve false. Los datos y el criterio de marcado son ficticios.

Edita el cuerpo de la función del primer bloque <script> dentro de <body>. Guarda el archivo y recarga la página.

Resultado esperado

checkDNAForAlzheimer(["GGTACCATCGGCTACATC","ATCGGCTAGGTACC","TCGAGGCTA","AGCTAGCTAG","GGCTATCG"]): true
checkDNAForAlzheimer(["ATCGGCTAAGGTC","GGTAGCTA","CTAGCTAGC","TACGGGCTAT","GCTACTGAC"]): true
checkDNAForAlzheimer(["GCTATCGG","AGCTAGCTA","TACGACTA","AGGTACCATCG","GGCTATACG"]): false
checkDNAForAlzheimer(["GGTACC","GGATCGGCTA"]): true
checkDNAForAlzheimer([]): false
