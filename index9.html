Ejercicio 9 · Calcular el saldo de una cuenta

Nivel intermedio

Antes de empezar

Al recorrer un array de objetos, en cada vuelta puedes leer la propiedad que necesitas.

const paquetes = [{ peso: 2 }, { peso: 5 }];
for (const paquete of paquetes) {
  console.log(paquete.peso);
}

Tu turno

Una aplicación bancaria recibe los movimientos de una cuenta que empieza con saldo cero. Cada movimiento tiene una fecha y un importe. Al abrir la cuenta, la pantalla muestra cuánto dinero queda.

Completa accountBalance(movements). Cada objeto tiene date para la fecha y value para el importe. Suma todos los value, positivos y negativos, y devuelve el saldo. Con una lista vacía, devuelve 0.

Edita el cuerpo de la función del primer bloque <script> dentro de <body>. Guarda el archivo y recarga la página.

Resultado esperado

accountBalance([{"date":"2023-04-01","value":100},{"date":"2023-04-02","value":-50},{"date":"2023-04-03","value":150}]): 200
accountBalance([{"date":"2023-04-04","value":500}]): 500
accountBalance([{"date":"2023-04-05","value":300},{"date":"2023-04-06","value":-100},{"date":"2023-04-07","value":-200},{"date":"2023-04-08","value":50}]): 50
accountBalance([{"date":"2023-04-09","value":-25}]): -25
accountBalance([]): 0

Comprueba tu solución

Cada prueba muestra la entrada, el resultado esperado y el obtenido.
